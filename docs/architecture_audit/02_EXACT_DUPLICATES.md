# GRaCEmo ViRa — Codebase Duplication and Redundancy Audit
# Document 02: Exact Duplicate Detection

**Audit Date:** November 2026  
**System:** GRaCEmo ViRa — Autonomous Robotics System  
**Method:** Cryptographic SHA-256 byte-by-byte content verification across all maintained source files.

---

## 1. Executive Summary of Exact Duplicates

Static hashing identified **56 distinct cryptographic clusters** comprising **138 maintained files** that are 100% byte-for-byte identical across multiple directory locations.

The exact duplicates fall into six distinct categories:
1. **3D Visual Meshes & MTL Palette:** 15 identical `.obj` and `.mtl` CAD files triplicated across workspace description, staging, and prototype description packages.
2. **ROS 2 Hardware Package:** 8 identical core implementation and launch files duplicated between workspace `gracemo_hardware` and prototype `gracemo_hardware`.
3. **Robot Bridge Subsystem:** Identical `interaction_bridge.py` duplicated between `adapters/robot-bridge/` and `ros2_ws/src/gracemo_bridge/`.
4. **Configuration & Maps:** Identical `places.json`, `destinations.json`, `sim_apartment_map.yaml`, `sim_apartment_map.pgm`, and `nav2_params.yaml` files stored in multiple paths.
5. **Operational Shell & Python Scripts:** Identical launcher scripts (`run_prototype.sh`, `stop_prototype.sh`, `stop_control_center.sh`, `verify_system_readiness.py`).
6. **Documentation & Reports:** Identical engineering reports duplicated across root `docs/`, `docs/blender_gazebo_integration/`, and prototype `docs/`.
